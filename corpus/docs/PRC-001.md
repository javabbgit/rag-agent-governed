# Application Intake

PRC-001 sets how Mortgage Operations receives mortgage applications from the broker portal and the branch, what a complete application contains, how the loan number DMC-YYYY-NNNNN is assigned, and the acknowledgement due within 1 business day.

## Application channels

Demo Mortgage Co. accepts mortgage applications through two channels: the broker portal and the branch. A mortgage broker submits an application through the broker portal on behalf of the borrower. A Loan Officer at a branch takes an application directly from a borrower and enters it into the same loan system. Both channels use the same application form and the same checks, so a file is handled in the same way whichever channel it came through. Mortgage Operations may not accept an application by any other route, such as a message or a personal email. If a borrower or broker sends documents or details outside the two channels, the staff member who receives them must ask for them to be submitted again through the broker portal or the branch. Broker Channel manages the relationship with brokers and may help a broker to submit, but it does not take applications.

## Minimum data for a complete application

An application is complete only when the loan system holds all of the following. For every borrower: the full legal name, the contact details, the identification documents required by Compliance, the employment and income details with the documents required by POL-002 or POL-008, the assets and the source of the down payment, and the consent to a credit bureau check. For the property: the address, the property type, the number of units, the occupancy and, for a purchase, the signed purchase agreement. For the loan: the product, the term, the loan amount, the amortization and the payment frequency requested. For the debts: every credit card, loan, line of credit and mortgage the borrower holds. Mortgage Operations checks the list on receipt and records the result in the file. An application with any item missing is incomplete.

## Loan number assignment

Mortgage Operations assigns a loan number to every application at intake, before any other step. The loan number has the format DMC-YYYY-NNNNN, where YYYY is the year in which the file was opened and NNNNN is a five-digit sequence number that the loan system issues. For example, DMC-2026-00123 identifies a file opened in 2026. The number stays the same for the whole life of the file, including the exception request, the closing and any renewal handled as a continuation of the file. The loan number is the only identifier that staff may use for a customer in a chat tool (see POL-011). Staff must quote the loan number in every message about the file, so that the file can be found and so that the customer is not named. Mortgage Operations never reuses a loan number, even for a withdrawn or declined file.

## Acknowledgement within 1 business day

Mortgage Operations must acknowledge every application within 1 business day of receiving it. The acknowledgement goes to the broker who submitted the application, or to the borrower when the application came through the branch. It confirms that the application was received, gives the loan number and states whether the application is complete or incomplete. For an incomplete application it lists each missing item in plain language. The acknowledgement does not say that the application will be approved, does not quote a rate other than one covered by a rate hold, and does not give an approval date. Staff must follow the communication standards in PRC-009. The business day count starts on the first business day on which the application is received by Mortgage Operations in the loan system.

## Incomplete applications and handoff to underwriting

Mortgage Operations does not pass an incomplete application to Underwriting. It keeps the file in an incomplete status, sends the list of missing items and waits for the broker or the branch to supply them. When the missing items arrive, Mortgage Operations checks the list again and records the result. A file that is complete is released to Underwriting, and the workflow in PRC-002 starts from the assignment stage. Mortgage Operations records the date and time at which the file was released. A broker or borrower who asks about the status of a file may be told whether it is incomplete, with Underwriting or decided, but may not be told what the decision will be. If a broker withdraws an application, Mortgage Operations records the withdrawal and closes the file under the same loan number.
